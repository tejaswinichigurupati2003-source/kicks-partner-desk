# 1-minute demo video: script and shot list

Record the screen at 1080p with your voice. Aim for 55 to 60 seconds. Open https://kicks-partner-desk.vercel.app in a clean browser window first.

| Time | On screen | Say |
|---|---|---|
| 0:00–0:07 | Overview page, empty | "Kicks wants to open many more franchise stores. This is Kicks Partner Desk. It takes the application journey off the expansion team." |
| 0:07–0:15 | Import → drop the Excel file (or Load practice data) | "The team uploads one Excel file. We clean it and show exactly what we changed, row by row." |
| 0:15–0:27 | Decision board, then open APP-006 (Redirected) and its reason trail | "Every applicant gets a decision and a plain reason. Farah's pin already has a store, so she's redirected to the nearest free pin. One store per pin code is checked on every run." |
| 0:27–0:36 | Same page: timeline, training in the preferred language, message tabs (Kannada) | "For partners who move forward: next steps, a dated timeline, training scaled to experience, and a message in Kannada, Hindi or English." |
| 0:36–0:50 | Open the assistant, type "APP-002 has withdrawn" | "New information saves at once. APP-002 withdraws, APP-003 moves up and wins pin 570001, and the card shows everyone it moved, with Undo." |
| 0:50–0:57 | Assumptions page, then Areas pin board | "Every number is an editable assumption, and the pin board shows who holds what." |
| 0:57–1:00 | Overview | "Code decides, the assistant explains, and the team stays in charge." |

Tips
- Do the withdraw step on a fresh run so APP-003 visibly moves up.
- Zoom the browser to 110% so text is readable on a phone.
- Say the link out loud or show it on the last frame.
